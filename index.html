Shot-specific image adjustment
Use the same controls for this shot only. Enabling copies the current roll-wide settings to this shot.

Processing order: invert the camera sRGB values (if enabled), decode to linear light, normalize each RGB channel to its roll min/max (editable above), apply brightness, contrast (pivoting at the middle of that range) and tint, apply the RGB curves over the min–max range, then apply the Master (W) curve to luminance only while preserving color. B&W desaturates after those corrections. RGB curves are flat by default. Double-click a curve to add a point; Ctrl+click a point to remove it; drag points to reshape the curve. RGB histograms show the actual input to each RGB curve; the Master (W) histogram shows luminance after RGB curves.
